# Invented synth-v3 fixture

Six hand-written fictional profiles and eight graded pairs in the same shape as the private
`ml/data/synth-v3` files. They exist so the format can be read and tested without the private
dataset. Nobody here is real, no employer is named, and the `why` field is an explanation for
readers only: the real pair files do not have it and no model ever sees it.

The second Mentee is a vocabulary-mismatch case (the occupation is never named) and the fourth
Mentor is a sparse cold-start profile.
